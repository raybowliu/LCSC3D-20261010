# KiCad 追加功能验证记录

验证日期：2026-10-31。本次为本地开发交付，应用版本沿用工作区的 2.4.42。

## 功能范围

- KiCad 的 Lib 区增加“追加”，与“合并”互斥，复用 AD 的追加配置页面和工程导入按钮。
- 选择已有 `.kicad_sym`、`.pretty` 或两者，只追加对应格式；只指定 `.kicad_pro` 时生成工程配套库，支持分别设置库目录、库名、3D 目录和独立器件目录。
- 同名旧符号保留原内容；相同封装复用，同名不同封装加序号，新符号引用最终封装名称。已有条目、模型、附加文件、注释及库表自定义内容保留。
- 配置页可直接将当前填写的库注册到工程的 `sym-lib-table` / `fp-lib-table`，不依赖下载列表或先保存配置。同名昵称指向其他库时报告冲突。已有库下载期间不自动导入；仅指定工程时自动注册本次成功生成的集中库。
- AD 与 KiCad 的模式、目标和配置分别保存。追加期间主页保存目录锁定，退出追加恢复普通导出设置。
- 修改已有符号库、工程库表前使用现有自动备份和恢复管理。写入失败恢复本次库修改；停止下载撤销整批输出。外部修改保留，恢复失败时在应用数据目录保留恢复资料。

## 验证结果

1. 全量单元测试执行 871 项。三个失败断言分别涉及两处新增配置键白名单和一处崩溃捕获测试初始化；更新这些测试后，三个专项复验全部通过。全量执行后未再次修改产品代码。
2. 新增后端测试覆盖 48 组已有库追加组合、12 组自定义工程输出组合，以及重复追加、同名符号、共享封装、封装重命名、内嵌/外部模型、外部修改、写入失败、取消恢复、库表冲突和备份恢复。
3. 新增界面测试覆盖点击追加打开配置、取消、合并互斥、单格式锁定、下载期间锁定、两种目标配置隔离和重启恢复、`.pretty` 目录选择、无下载列表的直接导入。
4. 最终 `outputs/LCSC3D.exe` 运行 18 组离线真实窗口验证，包括追加、重复追加、保留独立副本、仅指定工程、配置页直接导入，以及既有 AD / KiCad 导出和预览。实际窗口截图保存在已忽略的 `work/kicad-append/frozen-final/`，已检查页面布局。
5. KiCad 8.0.9、9.0.9、10.0.7 分别读取最终 EXE 产生的四组追加结果，并导出 SVG。前三组每组正确绘制 5 个符号单元和 3 个封装，工程专用库绘制 2 个符号单元和 2 个封装。
6. 已注入写入错误，验证诊断日志包含错误类型、处理阶段、错误编号和调用位置；诊断包排除隔离配置中的模拟登录会话。清除日志后继续写入，并可继续捕获崩溃。全部日志、备份及诊断检查使用隔离的 `LOCALAPPDATA`。
7. PyInstaller 重新构建根目录 EXE，逐模块核对 EXE 与工作区源码一致；交付源码 ZIP、使用说明和 SHA-256 校验文件同步到 `outputs/`。

本次原生 KiCad 验证覆盖库文件读取和二维绘制；未通过 KiCad 图形界面放置器件或检查完整 PCB。内嵌和外部模型的保留、资源内容及重复追加由后端测试核验。
