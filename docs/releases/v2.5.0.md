# LCSC3D 2.5.0

本版延续 2.4.5 的 KiCad“追加”功能，沿用 AD 的界面和配置流程，支持已有库追加、工程配套库导出和直接导入工程，并修复最小空工程被拒绝的问题。同时修复历史版本号的更新检测顺序，使用 2.5.0 版本号让旧版用户正常收到更新提醒。

## KiCad 追加与工程导入

- 在 KiCad 的 Lib 区选择“追加”，配置已有 `.kicad_sym` 符号库、`.pretty` 封装库目录或 `.kicad_pro` 工程；“追加”与“合并”互斥，AD 和 KiCad 的配置分别保存。
- 可以只指定符号库、只指定封装库或同时指定两者。已有符号保留原内容；相同封装自动复用，同名但内容不同的封装增加序号，并同步新符号中的封装引用。
- 追加已有库时，保留原有条目、3D 模型、附加文件和自定义内容。可选择额外保存独立器件副本。
- 仅指定 PCB 工程时，可分别设置符号库、封装库和 3D 模型的目录及库名，成功导出的集中库自动加入工程；同名库已存在时继续追加。
- 在追加配置页点击“将指定库导入到PCB工程”，可直接把当前填写的已有库加入工程，无须先保存配置或添加下载器件。引用保存在工程目录的 `sym-lib-table` 和 `fp-lib-table`，保留 `.kicad_pro` 原始内容。
- 重复导入相同引用时自动跳过；同名库昵称指向其他库时报告冲突。向已有库下载器件时只追加库内容，需要加入工程时使用配置页的导入按钮。

## 空工程导入修复

- 修复内容仅为 `{}` 的 `.kicad_pro` 工程导入失败。原实现强制要求 `meta` 字段，把有效的最小工程误判为格式无法识别；现在允许缺少该字段。
- 支持带换行、UTF-8 BOM 和自定义字段的工程，继续检查损坏 JSON、无效编码、非对象根节点和异常字段类型。导入成功后保留工程原始字节。

## 更新检测与旧版升级

- 使用 2.5.0 版本号，2.4.41、2.4.42 和 2.4.5 的已安装更新器均可识别本次更新；启动后台检查可提醒，也可在“设置 → 关于与支持 → 检查更新”中下载并重启。
- 兼容历史发行顺序 `2.4.4 → 2.4.41 → 2.4.42 → 2.4.5`，避免新版检测漏报或把较早发行误判为更新。其他正式版本继续按三段整数比较，相同版本不重复提醒。
- 更新日志记录当前版本、远端版本、实际排序和判断结果；没有新版时也保留远端版本，接口或附件异常继续记录错误原因链。
- 也可关闭旧程序后手动替换 `LCSC3D.exe`；用户配置继续保存在 `%LOCALAPPDATA%\LCSC3D\`。

## 文件保护与错误诊断

- 修改已有库和工程库表时沿用自动备份及恢复管理；写入失败或停止下载时撤销本次修改，外部并发修改受到保护。
- 补充已有库组合、重复追加、仅工程导出、空工程直接导入和异常输入回归；保留错误编号、异常类型、处理阶段与调用位置，验证清除日志后仍可继续记录错误和捕获崩溃。
